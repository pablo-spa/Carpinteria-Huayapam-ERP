⏰ Reglas de Asistencia
El conteo de horas para nómina empieza desde esta hora. Los trabajadores pueden checar antes pero las horas solo cuentan desde aquí.
Si llega dentro de este margen después de la hora de entrada, se toma como si hubiera llegado a tiempo.
Tiempo después del cual se considera Falta Automática.
El reloj anota la hora exacta, pero si sale dentro de la tolerancia, la asistencia registra esta hora oficial.
Margen después de la hora de salida considerado turno normal. Si se excede, cuenta como extras.
Se descuenta automáticamente de las horas trabajadas para la comida.
